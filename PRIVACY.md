# Privacy policy

Last updated: July 17, 2026

EZ IMG SAVE is a local browser extension. It does not collect, sell, share, or transmit personal information, browsing history, analytics, or saved images to the developer or to third-party services.

## What the extension accesses

The extension runs on regular webpages so it can find image elements and display a save button. When the user clicks that button, the extension reads the selected image URL and fetches that image from its original website for local conversion and download.

The extension does not inspect or retain unrelated page content. Image bytes are kept only in browser memory for the time needed to create the requested file.

## Local storage

Chrome local storage holds three preferences:

- whether save buttons are enabled;
- the selected output format;
- whether SVG/vector images should stay in their original format.

These settings stay in the user's Chrome profile and can be removed by uninstalling the extension or clearing its extension data.

## External services

EZ IMG SAVE has no developer-operated backend, analytics, advertising, telemetry, account system, or remote configuration. The only network request initiated by the extension is a request to the original image URL after the user explicitly chooses to save that image.

## Changes

Material changes to this policy will be documented in the repository and reflected in the Chrome Web Store listing before an updated data practice takes effect.

## Contact

Questions and privacy reports can be opened at <https://github.com/maxjustships/ez-img-save/issues>.
