# Changelog

All notable changes to this project will be documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-17

### Added

- Original, PNG, JPEG, and WebP output formats.
- Popup controls for output format and button visibility.
- Adaptive button placement for images smaller than 96 px.
- Local-only image conversion with explicit error feedback.
- Minimal-permission Manifest V3 build, automated checks, release packaging, and Chrome Web Store API workflow.

### Changed

- Replaced the upstream React/Turborepo boilerplate with a focused Vanilla TypeScript extension.
